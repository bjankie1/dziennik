# Plan 19-01: Backend Weekly Briefing Engine & Friday 18:00 Cloud Scheduler (`REQ-REPORT-01`, `REQ-REPORT-02`)

## Objective
Implement the automated backend service `functions/src/weekly_briefing_service.js` and register the Cloud Functions v2 scheduled trigger `scheduledWeeklyBriefing` (`0 18 * * 5` in `Europe/Warsaw`) plus the on-demand HTTP endpoint `sendWeeklyBriefingNow`.

## Tasks

1. **Create `functions/src/weekly_briefing_service.js`**:
   - Compute the upcoming Monday–Friday date window (`nextMonday` to `nextFriday`) relative to the current date in `Europe/Warsaw`.
   - Aggregate data from `students/{studentId}` and `family_tasks/{familyId}/tasks`:
     - **Upcoming Exams & Quizzes (`exams`)**: Filter exams falling within `[nextMonday, nextFriday]`, sorted chronologically by date and lesson number, including subject, category (`Sprawdzian` / `Kartkówka`), teacher, and scope (`description`).
     - **Daily Schedule Overview (`schedule`)**: Summarize each weekday (Poniedziałek–Piątek) with total lessons count and start–end time window (e.g., `Poniedziałek: 7 lekcji (08:00–14:25)`).
     - **Active Family Tasks (`tasks`)**: Include uncompleted tasks assigned to the student (`Oskar` / `all`) due in the upcoming week.
     - **Unexcused Absences Summary**: Count of unexcused absences requiring parent attention.
   - Format the HTML Telegram report (`formatWeeklyBriefingHtml`):
     - If exams > 0: Detailed chronological list of exams with material scope + daily schedule overview + pending tasks.
     - If exams == 0: Positive „🎉 Spokojny tydzień — brak zaplanowanych sprawdzianów i kartkówek!” message + daily schedule overview + pending tasks.
   - Dispatch to all paired Telegram chats (`parent` and `student` in `students/{studentId}/notification_settings` with `telegramEnabled == true` and `notifyWeeklyBriefing !== false`), and persist the latest briefing snapshot to `students/{studentId}/weekly_briefings/{weekIsoDate}`.

2. **Register `scheduledWeeklyBriefing` and `sendWeeklyBriefingNow` in `functions/index.js`**:
   - `exports.scheduledWeeklyBriefing = onSchedule({ region: "europe-west3", schedule: "0 18 * * 5", timeZone: "Europe/Warsaw" }, ...)`.
   - `exports.sendWeeklyBriefingNow = onRequest({ region: "europe-west3", cors: true }, ...)` for manual trigger and verification from the web app.

## Verification Criteria
- `node -c functions/src/weekly_briefing_service.js && node -c functions/index.js` exits with code 0.
- Formatter produces valid Telegram HTML (`parse_mode: "HTML"`) with all dynamic strings escaped via `escapeHtml`.
