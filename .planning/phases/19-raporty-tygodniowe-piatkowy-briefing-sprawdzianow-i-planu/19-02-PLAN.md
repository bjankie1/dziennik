# Plan 19-02: Client Weekly Briefing Generator, Preview Dialog & 1-Click Telegram Dispatch (`REQ-REPORT-01`, `REQ-REPORT-02`)

## Objective
Provide an interactive Weekly Briefing experience in the Flutter Web app so parents and students can preview the Friday weekly summary for any week, toggle the automated Friday 18:00 briefing in Notification Settings, and send the briefing on-demand to Telegram with 1 click.

## Tasks

1. **Extend `NotificationChannelSettings` (`lib/domain/models/notification_settings.dart`)**:
   - Add `notifyWeeklyBriefing` (`bool`, default `true`) to `NotificationChannelSettings` (`fromFirestore` & `toMap`).

2. **Create `WeeklyBriefingService` (`lib/core/services/weekly_briefing_service.dart`)**:
   - Generates a structured `WeeklyBriefingReport` for the upcoming (or currently selected) Monday–Friday school week from live data (`weekScheduleProvider`, `upcomingExamProvider`, `tasksStreamProvider`, `attendanceProvider`, `studentProfileProvider`).
   - Builds both:
     - Rich Telegram HTML payload (`toTelegramHtml()`) with escaped dynamic values,
     - Clean plain-text / Markdown summary (`toPlainText()`) for clipboard copying.
   - Provides `sendBriefingToTelegram(...)` which sends the briefing directly to the user's paired Telegram chat (`NotificationChannelsService.sendTelegramDirectMessage`) and/or triggers `sendWeeklyBriefingNow` Cloud Function.

3. **Create `WeeklyBriefingModal` (`lib/presentation/widgets/modals/weekly_briefing_modal.dart`)**:
   - Displays the visual preview of the Friday Weekly Briefing:
     - Header with week date range (`Poniedziałek–Piątek`), student name, and status badge (`X sprawdzianów` or `🎉 Spokojny tydzień — 0 sprawdzianów`).
     - Section 1: **Sprawdziany i kartkówki** (or positive calm-week card when empty).
     - Section 2: **Ramowy plan lekcji (Pn–Pt)** with daily hours and time range.
     - Section 3: **Zadania do wykonania (Smart To-Do)** na ten tydzień.
     - Action bar: **„Wyślij na Telegram”**, **„Kopiuj raport”**, and **„Powiadomienie Web Push”**.

4. **Integrate into `NotificationSettingsModal` and `WeekNavigatorBar`**:
   - Add the toggle `📊 Piątkowy briefing tygodniowy (Pt 18:00)` + button **„Podgląd i wyślij briefing”** in `NotificationSettingsModal`.
   - Add a compact **„Briefing tygodnia”** button in `WeekNavigatorBar` (`lib/presentation/screens/schedule/widgets/week_navigator_bar.dart`) next to the calendar export button.

## Verification Criteria
- `flutter analyze` passes with 0 issues.
- `flutter build web --release` succeeds and deploys cleanly to `https://lepsza-szkola.web.app`.
