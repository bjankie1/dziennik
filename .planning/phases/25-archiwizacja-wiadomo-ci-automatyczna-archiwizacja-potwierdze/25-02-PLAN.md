  <action>
    1. In `lib/presentation/screens/messages/messages_screen.dart`:
       - Add `bool _showArchived = false;` to `_MessagesScreenState`.
       - Compute `activeMessages = messages.where((m) => !m.isArchived).toList()`, `archivedMessages = messages.where((m) => m.isArchived).toList()`, and `unreadMessages = activeMessages.where((m) => m.isUnread).length`.
       - Above the messages list inside `_activeTab == 0`, render a control bar containing:
         - Filter chip (`ValueKey('messages_archive_filter_chip')`) with icon `Icons.archive_outlined` and label `'Pokaż zarchiwizowane (${archivedMessages.length})'` (toggles `_showArchived`).
         - When `!_showArchived && unreadMessages > 0`, show the unread count and `'Oznacz jako przeczytane'` button as before.
       - Filter displayed threads by `_showArchived ? archivedMessages : activeMessages`. When `_showArchived` is true and `archivedMessages.isEmpty`, show an empty state card `'Brak zarchiwizowanych wiadomości'`.
       - On each message card (`_buildMessageCard` / `_buildMessageTaskActionRow`), add an archive/restore action button (`ValueKey('archive_message_${thread.id}')`, label `thread.isArchived ? 'Przywróć' : 'Archiwizuj'`, icon `thread.isArchived ? Icons.unarchive_outlined : Icons.archive_outlined`) and a `'Zarchiwizowana'` badge when `thread.isArchived` is true (or `'Auto-archiwum'` when `thread.isAutoArchived && thread.isArchived`).
       - Clicking the button calls `ref.read(schoolRepositoryProvider).archiveMessage(thread.id, isArchived: !thread.isArchived)`, invalidates `messagesProvider`, and shows a floating `SnackBar` with `'Wiadomość przeniesiona do archiwum'` / `'Przywrócono wiadomość do skrzynki'` and a `'Cofnij'` `SnackBarAction`.
    2. In `lib/presentation/screens/messages/message_thread_screen.dart` and `lib/presentation/screens/messages/widgets/message_thread_header_card.dart`:
       - Add `_toggleArchiveStatus()` in `_MessageThreadScreenState` and an `IconButton` (`ValueKey('thread_archive_action_button')`, `Icons.archive_outlined` / `Icons.unarchive_outlined`, tooltip `'Archiwizuj wiadomość'` / `'Przywróć z archiwum'`) in `AppBar.actions`.
       - In `MessageThreadHeaderCard`, display a `'Zarchiwizowana'` badge when `thread.isArchived` is true.
  </action>
