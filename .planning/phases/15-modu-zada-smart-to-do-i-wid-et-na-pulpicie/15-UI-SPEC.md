## Visual & Interaction Contracts

### 1. `/zadania` Screen (`TasksScreen`) — Pattern matching `MessagesScreen` (D-04, D-05, D-06)
- **Top Segmented Control Bar (D-04.1):**
  - Container: `padding: EdgeInsets.all(4)`, `color: AppColors.surfaceContainerHigh.withValues(alpha: 0.6)`, `borderRadius: BorderRadius.circular(16)`.
  - 4 equal-width segments (`Expanded`):
    1. `Wszystkie` (icon `Icons.format_list_bulleted`, badge: count of all active uncompleted tasks, badge color `AppColors.primary`)
    2. `Dzisiaj` (icon `Icons.today`, badge: count of tasks due today + overdue, badge color `AppColors.error` if overdue > 0 else `AppColors.primary`)
    3. `Nadchodzące` (icon `Icons.upcoming_outlined`, badge: count of future tasks, badge color `AppColors.tertiaryContainer`)
    4. `Ukończone` (icon `Icons.task_alt`, badge: count of completed tasks, badge color `AppColors.secondary`)
- **Action & Quick Add Row (D-04.2):**
  - Height `44px`. Left side (`Expanded`): `AppColors.surfaceContainerLowest` container (`borderRadius: 14`) with a Quick Add text field (`Dodaj szybkie zadanie (np. Powtórka z biologii)...`), inline compact toggle pills for quick target due date (`Dzisiaj` / `Jutro`), priority (`🔴`/`🔵`/`⚪`), and assignee (`Oskar`/`Rodzic`/`Wspólne`), submitting immediately on `Enter` (`onSubmitted`) or trailing `+` icon tap.
  - Right side (`SizedBox(height: 44)`): `FilledButton.icon` with `Icons.add_task`, label `+ Nowe zadanie`, background `AppColors.primary`, `borderRadius: 14`, opening `TaskFormModal`.
- **Role Filter Chip Bar (D-04.3):**
  - Horizontal scrollable row of compact choice chips directly below the Action Row: `Wszystkie`, `Dla Oskara`, `Dla Rodzica`, `Wspólne`.
- **Chronological Grouping Sections (D-05):**
  - Within active tabs (`Wszystkie`, `Dzisiaj`, `Nadchodzące`), tasks are grouped under collapsible/clear section headers with item count pills:
    1. **„Zaległe”** — Header icon `Icons.warning_amber_rounded` + text in `AppColors.error` (`#BA1A1A`). Hidden when 0 overdue tasks.
    2. **„Dzisiaj”** — Header icon `Icons.wb_sunny_outlined` + text in `AppColors.onSurface`.
    3. **„Jutro / Nadchodzące”** — Header icon `Icons.calendar_month_outlined` + text in `AppColors.onSurface`.
    4. **„Bez terminu”** — Header icon `Icons.inbox_outlined` + text in `AppColors.onSurfaceVariant`.
  - In the `Ukończone` tab, tasks are sorted descending by `completedAt`.
- **Task Card Anatomy (D-01, D-02, D-03, D-06):**
  - Container: `AppColors.surfaceContainerLowest` (`#FFFFFF`), `borderRadius: BorderRadius.circular(16)`, border `1px solid AppColors.outlineVariant.withValues(alpha: 0.3)` (or `AppColors.error.withValues(alpha: 0.4)` if overdue), subtle shadow `BoxShadow(color: Color(0x05000000), blurRadius: 8, offset: Offset(0, 2))`.
  - Left: Custom rounded `Checkbox` (`borderRadius: 6`, 22x22px visual box inside 44x44px tap area). Tapping triggers immediate optimistic Firestore update (`isCompleted`, `completedByRole`, `completedByName`, `completedAt`) with animated strike-through.
  - Center:
    - Row 1: Task title (`16px`, `w600`, `AppColors.onSurface`) + optional subject/category badge (e.g. `Matematyka`, `Sprawdzian`, `Opłata/Formalności`).
    - Row 2 (optional): 1–2 line description preview (`14px`, `w400`, `AppColors.onSurfaceVariant`, `maxLines: 2`, `TextOverflow.ellipsis`).
    - Row 3 (Metadata & Attribution Footer): Priority pill (`Wysoki` / `Normalny` / `Niski`), Due Date pill (`Dzisiaj`, `Jutro`, or `d MMM`, colored `AppColors.error` if overdue), Role badge (`Dla Oskara` / `Dla Rodzica` / `Wspólne`), and attribution label (`Dodał: Tata` or `Dodał: Tata • Ukończył: Oskar`).
  - Right:
    - Clicking anywhere on the card body opens `TaskFormModal` in edit/detail mode.
    - Delete icon button (`Icons.delete_outline`, `AppColors.outline` → `AppColors.error` on hover) if `!(isStudent && task.createdByRole == 'parent')`.
    - If `isStudent && task.createdByRole == 'parent'` (D-03): Instead of a delete button, display a subtle lock badge (`Icons.lock_person_outlined`, `14px`, `AppColors.tertiary`) with tooltip `Zadanie zlecone przez Rodzica — brak możliwości usunięcia`.

### 2. Dashboard Bento Grid Widget: „Zadania na dziś” (D-07, D-08)
- **Desktop Placement (D-07):**
  - Mounted in `DashboardScreen._buildDesktopMessagesColumn` (Column 2, center column `flex: 5`) **at the very top of Column 2, directly above the „Wiadomości i Komunikaty” card**, separated by `const SizedBox(height: 20)`.
- **Mobile Placement (D-07):**
  - Mounted in `DashboardScreen._buildMobileDashboard` **directly below the Daily Schedule (`Harmonogram dnia`) section and above the Messages / Recent Grades sections**, separated by `const SizedBox(height: 16)`.
- **Widget Content & Interaction (D-08):**
  - Card container matching Dashboard Bento cards: `AppColors.surfaceContainerLowest`, `borderRadius: BorderRadius.circular(16)`, `border: Border.all(color: AppColors.outlineVariant.withValues(alpha: 0.3))`, `padding: EdgeInsets.all(20)`.
  - Header Row:
    - Left: Icon container (`Icons.checklist_rtl_rounded`, `AppColors.primary` on `AppColors.primaryFixed` 36x36px rounded square) + Title `Zadania na dziś` (`16px`, `w600`) + counter badge showing active urgent tasks count (with overdue badge in `AppColors.error` if any overdue tasks exist).
    - Right: Compact `+` icon button (`IconButton.filledTonal`, 32x32px, opening `TaskFormModal` or toggling inline quick-add row) + `TextButton` `Zobacz wszystkie (X) →` navigating via `context.go('/zadania')`.
  - Task List (up to 5 most urgent active tasks):
    - Sorted by: Overdue first → Due Today → Priority (`high` → `medium` → `low`), prioritizing tasks assigned to the logged-in user's role (`student` or `parent`) and `shared`.
    - Each compact row (`padding: EdgeInsets.symmetric(vertical: 8, horizontal: 10)`, `borderRadius: 12`) displays: Interactive `Checkbox` (one-click completion in Firestore with smooth strike-through transition), task title (`14px`, `w600`), subject/role micro-pill, and due date tag (`Zaległe` in red or `Dzisiaj`).

### 3. Navigation & Routing Integration (D-09)
- **Route:** `/zadania` registered as a dedicated branch in `StatefulShellRoute.indexedStack` in `lib/presentation/routes/app_router.dart`.
- **Desktop (`AppSidebar`):**
  - Both `Zadania` (icon `Icons.task_alt_outlined` / `Icons.task_alt`, badge showing count of overdue + today's active tasks) and `Czat Rodzinny` (icon `Icons.forum_outlined` / `Icons.forum`, badge showing unread chat messages) appear as full sidebar items.
- **Mobile (`MainNavigationScreen` + `AppHeader`):**
  - Bottom `NavigationBar` displays 6 primary destinations:
    1. `Pulpit` (`Icons.dashboard_outlined`)
    2. `Plan` (`Icons.calendar_today_outlined`)
    3. `Oceny` (`Icons.grade_outlined`)
    4. `Frekwencja` (`Icons.fact_check_outlined`)
    5. `Wiadomości` (`Icons.mail_outline`)
    6. `Zadania` (`Icons.task_alt_outlined`, with badge for active today/overdue tasks)
  - `Czat Rodzinny` on mobile is placed in the top `AppHeader` (next to notifications and user role/avatar) as an `IconButton` (`Icons.chat_bubble_outline_rounded`) wrapped in a `Badge` displaying `chatUnreadCount` when `> 0`, navigating to `/czat`.

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `TasksScreen` list & Dashboard `Zadania na dziś` Bento widget | ✅ covered | When Firestore `family_tasks/{familyId}/tasks` is completely empty on first launch, seed fallback starter tasks demonstrating Parent ↔ Oskar collaboration; when a filter tab has 0 matches, render the documented Empty State card (`Brak zadań w tym widoku`) or celebratory Bento state (`Wszystkie zadania na dziś wykonane! 🎉`). |
| loading | `TasksScreen` & Dashboard Bento widget (`StreamProvider`) | ✅ covered | While `tasksStreamProvider` is in `AsyncLoading` state, render a centered `CircularProgressIndicator(color: AppColors.primary)` inside a `16px` rounded surface card without shifting the top Segmented Control Bar or Bento Grid columns. |
| error | `TasksScreen` & Firestore mutation failures | ✅ covered | Stream errors render the documented Error State copy with a `Spróbuj ponownie` button (`ref.invalidate(tasksStreamProvider)`); failed checkbox or modal writes show a floating `SnackBar` in `AppColors.error`. |
| populated | Chronological task sections (`Zaległe`, `Dzisiaj`, `Jutro / Nadchodzące`, `Bez terminu`) | ✅ covered | Only non-empty chronological sections are rendered in active tabs so the user never sees empty section headers cluttering the viewport. |
| zero-one-many | Dashboard Bento `Zadania na dziś` list & Mobile 6-item `NavigationBar` | ✅ covered | Dashboard Bento widget caps visible rows at 5 urgent items and routes overflow via `Zobacz wszystkie (X) →`; Mobile `NavigationBar` uses `LabelBehavior.alwaysShow` with compact `11px` labels so all 6 tabs fit cleanly on 360px+ screens while `Czat Rodzinny` lives in `AppHeader`. |
| long-text | Task card title, description, and subject pills | ✅ covered | Task card titles wrap up to 2 lines (`maxLines: 2`, `TextOverflow.ellipsis`), descriptions cap at 2 lines in list view and expand fully inside `TaskFormModal`, and metadata pills wrap inside a `Wrap(spacing: 6, runSpacing: 6)` to prevent horizontal overflow on mobile. |
| role-permissions | Student vs Parent task deletion & editing (`D-03`) | ✅ covered | When `isStudent == true` and `task.createdByRole == 'parent'`, the delete button in both the task card and `TaskFormModal` is hidden/disabled and replaced by the parent-lock badge (`Zadanie zlecone przez Rodzica`), while completion toggle and note editing remain enabled. |
| optimistic-ui | One-click checkbox completion on Dashboard & `/zadania` (`D-08`) | ✅ covered | Tapping a task checkbox immediately applies the strike-through style and attribution footer (`Ukończył: Oskar` / `Ukończył: Rodzic`) while persisting to Firestore in real time. |
