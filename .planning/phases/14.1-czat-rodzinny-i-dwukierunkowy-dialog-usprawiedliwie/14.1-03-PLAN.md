# Plan 14.1-03: Real-Time Family Chat & Navigation Integration (Wave 3)

## Executive Summary
Plan 14.1-03 completes Phase 14.1 by delivering the real-time Family Chat feature between parent and student (REQ-CHAT-01, D-01, D-04). It implements `FamilyChatRepository` and Riverpod providers with Firestore live streaming, creates the dedicated `FamilyChatScreen` under `/czat`, integrates quick access shortcuts and dynamic unread badges in `AppDesktopHeader` and `AppSidebar`, supports interactive justification cards inside the chat stream, and handles real-time in-app notifications.

---

## Threat Model & Security Controls
<threat_model>
- **Threat T-14.1-04 (Chat message spamming / unbounded query load):** Fast message exchanges could trigger large Firestore document reads.
  - *Mitigation:* `familyChatMessagesProvider` queries messages ordered by `createdAt desc` with a `limit(100)` clause, caching recent messages in memory.
</threat_model>
