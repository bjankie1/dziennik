# Plan 14.1-02: Two-Way Excuse Rejection Dialogue UI (Wave 2)

## Executive Summary
Plan 14.1-02 implements the complete interactive UI for the two-way excuse rejection dialogue (REQ-ROLE-04, D-02, D-03). It updates the pending request card on both desktop Bento Grid and mobile views in `DashboardScreen` and `AttendanceScreen` to present a dual-action row (`[ 123 Zatwierdź (PIN) ]` + `[ Odrzuć ]`), introduces `ParentRejectionModal` with a dedicated comment input and quick suggestions, and builds `StudentResponseModal` allowing Oskar to review the parent's comment and reply / re-request with extra explanations.

---

## Threat Model & Security Controls
<threat_model>
- **Threat T-14.1-03 (State desynchronization during re-request):** If an excuse request is answered while the parent is viewing it, UI might show outdated action buttons.
  - *Mitigation:* `justificationRequestsProvider` invalidates on approval/rejection/response, triggering reactive UI updates across screens.
</threat_model>
