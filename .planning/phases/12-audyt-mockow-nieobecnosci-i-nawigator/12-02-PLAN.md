# Plan 12-02: Frekwencja w planie lekcji i stała szerokość przełącznika tygodni

**Phase:** 12 — audyt-mockow-nieobecnosci-i-nawigator  
**Plan ID:** 12-02

**Decisions Covered:** D-01, D-02, D-03, D-06, D-07, D-08

## 1. Executive Summary

Niniejszy plan realizuje dwa kluczowe ulepszenia modułu planu lekcji:
1. **Wzbogacenie slotów lekcyjnych o statusy frekwencji (REQ-TIMETABLE-05):** Naniesienie statusu obecności/nieobecności, zwolnienia, spóźnienia oraz oczekującej weryfikacji usprawiedliwienia bezpośrednio na kafelki planu w siatce tygodniowej (`WeeklyGridView`), agendzie dziennej (`AgendaLessonCard`) oraz w modalu szczegółów zajęć (`LessonDetailsModal`).
2. **Nieruchome przyciski nawigacji tygodniowej (REQ-TIMETABLE-06):** Zamknięcie selektora tygodnia w `WeekNavigatorBar` w kontenerze o stałej szerokości (~420px na desktopie/tabletach) z przyciskami `[<]` i `[>]` przypiętymi do skrajnych krawędzi i wyśrodkowanym zakresem dat, co eliminuje przesuwanie kursora przy wielokrotnym klikaniu strzałek, z elastycznym dopasowaniem poniżej 500px na mobile.

## 3. Detailed Tasks

### Task 1: Rozszerzenie modelu `LessonSlot` i wzbogacenie planu lekcji o frekwencję w repozytorium
- **Pliki:**
  - `lib/domain/models/lesson_slot.dart`
  - `lib/data/repositories/firestore_school_repository.dart`
- **Kroki implementacji:**
  1. **Aktualizacja `LessonSlot`:**
     - Dodać import `attendance_record.dart`.
     - Dodać pola:
       ```dart
       final AttendanceType? attendanceType;
       final JustificationStatus? attendanceJustificationStatus;
       final String? attendanceNote;
       ```
     - Zaktualizować konstruktor `LessonSlot` (pola opcjonalne) oraz metodę `copyWith(...)`.
  2. **Korelacja frekwencji w `FirestoreSchoolRepository`:**
     - W metodzie `_parseTimetableForDay`:
       - Przyjąć opcjonalną listę `List<AttendanceRecord>? dayAttendance`.
       - Dla każdej lekcji z danego dnia znaleźć odpowiadający rekord frekwencji po `lessonNumber` (lub po nazwie przedmiotu, jeśli lekcja jest unikalna):
         ```dart
         AttendanceType? attType;
         JustificationStatus? attJustStatus;
         String? attNote;
         
         if (dayAttendance != null && dayAttendance.isNotEmpty) {
           final lessonNumber = item['lessonNumber'] as int? ?? 1;
           final matchedAtt = dayAttendance.firstWhere(
             (a) => a.lessonNumber == lessonNumber,
             orElse: () => dayAttendance.firstWhere(
               (a) => a.subjectName.toLowerCase() == subject.toLowerCase(),
               orElse: () => const AttendanceRecord(
                 id: '',
                 date: DateTime(1970),
                 lessonNumber: -1,
                 subjectName: '',
                 type: AttendanceType.present,
                 timeSlot: '',
               ),
             ),
           );
           if (matchedAtt.lessonNumber != -1) {
             attType = matchedAtt.type;
             attJustStatus = matchedAtt.justificationStatus;
             attNote = matchedAtt.justificationReason;
           }
         }
         ```
       - Przekazać `attendanceType: attType`, `attendanceJustificationStatus: attJustStatus`, `attendanceNote: attNote` do zwracanego `LessonSlot`.
     - W `getScheduleForDay`, `getTodaySchedule` oraz `getWeekSchedule`:
       - Pobrać rekordy frekwencji przez `getAttendanceRecords()` (co uwzględnia także `_localJustificationOverrides`).
       - Przefiltrować frekwencję na poszczególne dni i przekazać do `_parseTimetableForDay`.
- **Weryfikacja:**
  - `flutter analyze` potwierdza brak błędów typowania w `LessonSlot` i repozytorium.

### Task 3: Pigułki frekwencji w `WeeklyGridView`, blok w `AgendaLessonCard` oraz modal szczegółów
- **Pliki:**
  - `lib/presentation/screens/schedule/widgets/weekly_grid_view.dart`
  - `lib/presentation/screens/schedule/widgets/agenda_lesson_card.dart`
  - `lib/presentation/screens/schedule/widgets/lesson_details_modal.dart`
- **Kroki implementacji:**
  1. **Kompaktowa pigułka w siatce tygodniowej (`WeeklyGridView._buildLessonCell`) (D-01, D-02):**
     - Obok numeru sali w nagłówku komórki lekcji dodać pigułkę frekwencji, o ile typ obecności to nie `present` (lub brak):
       ```dart
       Widget? attendanceBadge;
       if (slot.attendanceType != null && slot.attendanceType != AttendanceType.present) {
         final isPending = slot.attendanceJustificationStatus == JustificationStatus.requested;
         if (isPending) {
           attendanceBadge = Container(
             padding: const EdgeInsets.symmetric(horizontal: 4, vertical: 1),
             decoration: BoxDecoration(
               color: const Color(0xFFFEF3C7),
               borderRadius: BorderRadius.circular(4),
               border: Border.all(color: const Color(0xFFF59E0B).withValues(alpha: 0.5)),
             ),
             child: const Text(
               'Weryfikacja',
               style: TextStyle(fontSize: 8, fontWeight: FontWeight.w800, color: Color(0xFFB45309)),
             ),
           );
         } else {
           Color badgeBg;
           Color badgeText;
           String badgeLabel;
           switch (slot.attendanceType!) {
             case AttendanceType.absent:
               badgeBg = const Color(0xFFFEE2E2);
               badgeText = AppColors.error;
               badgeLabel = 'Nieobecność';
               break;
             case AttendanceType.excused:
               badgeBg = const Color(0xFFDCFCE7);
               badgeText = const Color(0xFF15803D);
               badgeLabel = 'Usprawiedliwiona';
               break;
             case AttendanceType.exempted:
               badgeBg = const Color(0xFFE0F2FE);
               badgeText = const Color(0xFF0369A1);
               badgeLabel = 'Zwolnienie';
               break;
             case AttendanceType.late:
             case AttendanceType.excusedLate:
               badgeBg = const Color(0xFFFEF9C3);
               badgeText = const Color(0xFFA16207);
               badgeLabel = 'Spóźnienie';
               break;
             default:
               badgeLabel = '';
               badgeBg = Colors.transparent;
               badgeText = Colors.transparent;
           }
           if (badgeLabel.isNotEmpty) {
             attendanceBadge = Container(
               padding: const EdgeInsets.symmetric(horizontal: 4, vertical: 1),
               decoration: BoxDecoration(
                 color: badgeBg,
                 borderRadius: BorderRadius.circular(4),
               ),
               child: Text(
                 badgeLabel,
                 style: TextStyle(fontSize: 8, fontWeight: FontWeight.w800, color: badgeText),
               ),
             );
           }
         }
       }
       ```
     - Umieścić `attendanceBadge` obok numeru sali (`Row` z salą i pigułką).
  2. **Blok informacyjny frekwencji w `AgendaLessonCard` (D-03):**
     - Jeśli `slot.attendanceType != null && slot.attendanceType != AttendanceType.present`:
       - Wyświetlić dedykowany banerek wewnątrz karty:
         - Tytuł statusu (np. „Nieobecność”, „Usprawiedliwiona”, „Oczekuje na weryfikację”)
         - Jeśli jest podany powód rodzica (`slot.attendanceNote`): „Powód rodzica: ${slot.attendanceNote}”
         - Status decyzji: np. „Oczekuje na zatwierdzenie przez wychowawcę” lub „Zaakceptowane”.
  3. **Pełna sekcja frekwencji w `LessonDetailsModal` (D-03):**
     - Dodać boks informacji o frekwencji z ikoną, statusem decyzji i powodem:
       ```dart
       if (slot.attendanceType != null && slot.attendanceType != AttendanceType.present) ...[
         const SizedBox(height: 14),
         _buildAttendanceDetailsSection(context, slot),
       ]
       ```
     - Jeśli nieobecność jest nieusprawiedliwiona (`AttendanceType.absent` i status `none`), wyświetlić przycisk „Zgłoś e-usprawiedliwienie”, otwierający modal usprawiedliwienia.
- **Weryfikacja:**
  - Uruchomienie `flutter analyze` oraz weryfikacja wizualna testem widgetowym.

## 4. Acceptance Criteria & Verification Plan

1. **Widoczność statusów w siatce (D-01, D-02):**
   - Na kafelkach lekcji z odnotowaną obecnością inną niż normalna pojawia się estetyczna, czytelna pigułka obok sali.
   - Pigułka `Weryfikacja` / `Oczekuje na weryfikację` ma kolor bursztynowy i wyróżnia się od czerwonej nieobecności.
2. **Szczegóły frekwencji (D-03):**
   - Karta agendy oraz modal szczegółów wyświetlają powód zgłoszenia oraz decyzję wychowawcy.
3. **Nieruchomy przełącznik tygodni (D-06, D-07, D-08):**
   - Kontener nawigatora ma stałą szerokość (~430px) na ekranach >= 500px.
   - Pozycja strzałki `[>]` nie ulega zmianie przy przełączaniu tygodni, niezależnie od pojawiania się badge'a 'Aktualny' czy różnej długości nazw miesięcy.
   - Na ekranach mobile (< 500px) pasek zachowuje pełną elastyczność bez błędów overflow.
