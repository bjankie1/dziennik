<objective>
Fix the misaligned histogram bars in `GradeDistributionCard` so all 6 MEN grade bars (`1..6`) and their scale labels always share an exact, non-overflowing horizontal baseline.

Purpose: In the current implementation, each bar column is placed inside an 80px-tall `Container` with `Column(mainAxisAlignment: MainAxisAlignment.end)` containing `Text('$count')` + `4px` + `Container(height: barHeight)` + `4px` + `Text('$gradeNum')`. When a bar reaches maximum height (`barHeight = 34.0`), the combined height of the two text boxes, spacing, and bar exceeds the available height, causing the tallest column (e.g., grade `1` with count `7`) to overflow from the top (`y = 0`) downward in release web builds—pushing its bar bottom edge and its `1` label ~10px lower than bars `2..6`. Separating the fixed-height count slot, bar area, and fixed-height grade label slot with sufficient vertical budget guarantees every bar starts on the exact same baseline.
Output: Updated `GradeDistributionCard` widget, baseline-alignment widget test in `grades_presentation_test.dart`, and live Firebase Hosting deployment.
</objective>
